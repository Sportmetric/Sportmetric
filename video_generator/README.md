# Innometrics: κάθετα βίντεο για Reels και TikTok

Φτιάχνει αυτόματα 30 κάθετα βίντεο (1080x1920, 9:16, 20-40 δευτ.) για τα smartglasses της Innometrics.
Είναι εντελώς δωρεάν: δεν χρειάζεται συνδρομή ούτε κλειδί API.

| Τι | Με τι |
|---|---|
| Ελληνική φωνή | edge-tts (Νέστορας και Αθηνά, εναλλάξ) |
| Υπότιτλοι συγχρονισμένοι με τη φωνή | faster-whisper, τρέχει τοπικά στον υπολογιστή σου |
| Μοντάζ, λογότυπο, μουσική | ffmpeg |

Για κάθε σενάριο του `scripts.json` βγαίνει ένα βίντεο με:

- φωνή που διαβάζει το σενάριο,
- τυχαία πλάνα από τα δικά σου βίντεο, κομμένα για κάθετη οθόνη,
- μεγάλους λευκούς υπότιτλους με μαύρο περίγραμμα στο κέντρο,
- το λογότυπο πάνω δεξιά,
- απαλή μουσική χαμηλά, κάτω από τη φωνή.

## Φάκελοι

```
video_generator\
├── make_videos.py      ← το πρόγραμμα
├── scripts.json        ← τα 30 σενάρια (μπορείς να τα αλλάξεις)
├── requirements.txt
├── logo.png            ← ΕΣΥ: το λογότυπό σου (ιδανικά PNG με διάφανο φόντο)
├── clips\              ← ΕΣΥ: τα βίντεο με τα γυαλιά (.mp4, .mov)
├── music\              ← ΕΣΥ: 1 ή περισσότερα μουσικά κομμάτια (.mp3)
└── output\             ← εδώ βγαίνουν τα βίντεο και το captions.txt
```

## Εγκατάσταση στα Windows (μία φορά)

### 1. Python

1. Κατέβασε την Python 3.12 από το https://www.python.org/downloads/windows/
2. Στο πρώτο παράθυρο της εγκατάστασης **τσέκαρε το «Add python.exe to PATH»** και πάτα «Install Now».
3. Άνοιξε το **PowerShell** (Έναρξη, γράψε `powershell`, Enter) και έλεγξε:
   ```
   python --version
   ```
   Πρέπει να δεις κάτι σαν `Python 3.12.x`.

### 2. ffmpeg

Στο PowerShell:
```
winget install Gyan.FFmpeg
```
**Κλείσε και ξανάνοιξε το PowerShell**, και έλεγξε:
```
ffmpeg -version
```

Αν δεν έχεις το `winget`: κατέβασε το `ffmpeg-release-essentials.zip` από το https://www.gyan.dev/ffmpeg/builds/,
αποσυμπίεσέ το στο `C:\ffmpeg` και πρόσθεσε το `C:\ffmpeg\bin` στη μεταβλητή Path
(Έναρξη → «Επεξεργασία των μεταβλητών περιβάλλοντος του συστήματος» → Μεταβλητές περιβάλλοντος → Path → Επεξεργασία → Δημιουργία).

### 3. Οι βιβλιοθήκες Python

Πήγαινε στον φάκελο του προγράμματος (άλλαξε τη διαδρομή αν τον έβαλες αλλού):
```
cd C:\Users\ΤοΌνομάΣου\Desktop\video_generator
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```
Αν το PowerShell πει ότι «running scripts is disabled», τρέξε μία φορά
`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`, απάντησε `Y` και ξανατρέξε την εντολή `Activate.ps1`.

### 4. Βάλε τα αρχεία σου

- Τα βίντεο με τα γυαλιά στο `clips\`. Όσο περισσότερα και πιο ποικίλα, τόσο καλύτερα (τουλάχιστον 8-10 πλάνα).
  Κάθετα πλάνα βγαίνουν καλύτερα. Τα οριζόντια κόβονται στο κέντρο.
- Μουσική στο `music\`: χρησιμοποίησε μόνο μουσική που επιτρέπεται για εμπορική χρήση, π.χ. από τη
  YouTube Audio Library ή το Pixabay Music. Αν βάλεις πολλά κομμάτια, κάθε βίντεο παίρνει ένα τυχαίο.
- Το λογότυπο ως `logo.png` δίπλα στο `make_videos.py`.

## Εκτέλεση

Κάθε φορά που ανοίγεις νέο PowerShell:
```
cd C:\Users\ΤοΌνομάΣου\Desktop\video_generator
.\.venv\Scripts\Activate.ps1
python make_videos.py
```

- Χρειάζεται internet για τη φωνή. Τα υπότιτλα φτιάχνονται τοπικά.
- Την πρώτη φορά το faster-whisper κατεβάζει το μοντέλο «small» (~480 MB). Μετά δουλεύει χωρίς να ξανακατεβάσει τίποτα.
- Κάθε βίντεο θέλει περίπου 1-3 λεπτά, ανάλογα με τον υπολογιστή.
- Αν σταματήσεις στη μέση ή κάποιο αποτύχει, ξανατρέξε την ίδια εντολή: όσα βίντεο υπάρχουν ήδη παραλείπονται.

Χρήσιμες παραλλαγές:
```
python make_videos.py --only 3,7,12     # μόνο συγκεκριμένα σενάρια
python make_videos.py --force           # ξαναφτιάχνει όλα από την αρχή (νέα τυχαία πλάνα)
python make_videos.py --only 5 --force  # ξαναφτιάχνει μόνο το 5
```

## Αποτέλεσμα

- `output\innometrics_01.mp4` … `output\innometrics_30.mp4`
- `output\captions.txt`: για κάθε βίντεο η λεζάντα και τα hashtags, έτοιμα για αντιγραφή στο Instagram και στο TikTok.

## Αλλαγές

**Σενάρια:** άνοιξε το `scripts.json` με το Notepad και άλλαξε τα κείμενα. Κάθε σενάριο έχει:
`hook` (η πρώτη φράση, μέσα στα 2 πρώτα δευτερόλεπτα), `body`, `cta`, `caption`, `hashtags`.
Μπορείς να προσθέσεις και `"voice": "el-GR-AthinaNeural"` σε ένα σενάριο για να ορίσεις τη φωνή του.
Μετά τρέξε `python make_videos.py --only <αριθμός> --force` για να ξαναφτιαχτεί.

**Εμφάνιση:** στην αρχή του `make_videos.py` υπάρχουν οι ρυθμίσεις:

| Ρύθμιση | Τι αλλάζει |
|---|---|
| `FONT_SIZE`, `OUTLINE`, `FONT_NAME` | μέγεθος, περίγραμμα και γραμματοσειρά υποτίτλων |
| `MAX_WORDS_PER_LINE` | πόσες λέξεις εμφανίζονται κάθε φορά |
| `LOGO_WIDTH`, `LOGO_MARGIN` | μέγεθος και θέση λογότυπου |
| `MUSIC_VOLUME` | ένταση μουσικής (0.12 = χαμηλά, 0.25 = πιο δυνατά) |
| `SEGMENT_MIN`, `SEGMENT_MAX` | πόσο κρατάει κάθε πλάνο |
| `WHISPER_MODEL` | `small` (γρήγορο) ή `medium` (πιο ακριβές, πιο αργό) |
| `TTS_PRONUNCIATION` | πώς προφέρει η φωνή λέξεις όπως «Skroutz» ή «Bluetooth» |

## Προβλήματα

| Μήνυμα | Λύση |
|---|---|
| `Δεν βρέθηκε το ffmpeg` | Βήμα 2, και άνοιξε νέο PowerShell. |
