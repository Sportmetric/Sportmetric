# InnoMetrics — εσωτερικά εργαλεία

Εσωτερικό πρόγραμμα της InnoMetrics (πρώην SportMetrics ΙΚΕ) για τη διαχείριση και την ανάπτυξη της εταιρείας.

Όλη η εφαρμογή είναι το αρχείο `app/index.html`, δημοσιευμένο ως ιδιωτική σελίδα (Artifact) στο claude.ai με δική της βάση δεδομένων.
Τα δεδομένα δεν αποθηκεύονται σε αυτό το repository· εδώ φυλάσσεται μόνο ο κώδικας.

## Καρτέλες

| Καρτέλα | Τι κάνει |
|---|---|
| Έξοδα | Καταγραφή εξόδων ανά κατηγορία. Ένα έξοδο «Εμπόρευμα» με προϊόν και τεμάχια προσθέτει απόθεμα. |
| Έσοδα | Καταγραφή εσόδων ανά κανάλι (Skroutz, λιανική, εταιρικοί). Ένα έσοδο με προϊόν και τεμάχια αφαιρεί απόθεμα και προτείνει ποσό από τον κατάλογο. |
| Απόθεμα | Απόθεμα ανά προϊόν, αξία, ειδοποιήσεις χαμηλού αποθέματος, διορθώσεις (αρχικό απόθεμα, ελαττωματικά, δείγματα). |
| Προϊόντα | Κατάλογος με κόστη, τιμές, EAN και περιθώριο ανά τεμάχιο. |
| Συνεργάτες | Καταστήματα και εταιρικοί πελάτες: στάδιο, τελευταία επαφή, επόμενη ενέργεια, ιστορικό, βοηθός email. |
| Balance | Έσοδα, έξοδα, αποτέλεσμα και σωρευτικά ανά μήνα. |

Κάθε καρτέλα έχει εξαγωγή σε CSV.

## Innometrics Control Center (dashboard/)

Ο φάκελος `dashboard/` περιέχει το νέο εσωτερικό admin dashboard (React + Vite + TypeScript).
Οδηγίες εκτέλεσης και σύνδεσης με πραγματικά δεδομένα: `dashboard/README.md`.

> Το repository είναι δημόσιο. Τα δεδομένα στο `dashboard/src/data/seed/` είναι ενδεικτικά (mock).
> Τα πραγματικά δεδομένα εισάγονται μόνο τοπικά από *Settings → Import backup* και δεν μπαίνουν ποτέ στο git.
