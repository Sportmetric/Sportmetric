# InnoMetrics — εσωτερικά εργαλεία

Εσωτερικό πρόγραμμα της InnoMetrics (πρώην SportMetrics ΙΚΕ) για τη διαχείριση και την ανάπτυξη της εταιρείας.

## Ενότητες

| # | Ενότητα | Κατάσταση | Αρχείο |
|---|---------|-----------|--------|
| 1 | Έξοδα (καταγραφή, σύνολα ανά μήνα και κατηγορία, CSV για λογιστή) | ✅ Έτοιμη | `app/expenses.html` |
| 2 | Αγορές από εργοστάσιο και απόθεμα | Επόμενη | – |
| 3 | Συνεργάτες (καταστήματα, εταιρικοί πελάτες, follow-ups, emails) | Σχεδιάζεται | – |
| 4 | Ανάπτυξη (πωλήσεις, έξοδα, κέρδος, προτάσεις) | Σχεδιάζεται | – |

Κάθε ενότητα δημοσιεύεται ως ιδιωτική σελίδα (Artifact) στο claude.ai με δική της βάση δεδομένων.
Τα δεδομένα δεν αποθηκεύονται σε αυτό το repository· εδώ φυλάσσεται μόνο ο κώδικας.
